- On May 28, 2026 Mistral launched Vibe, 'one agent for long-running, multi-step work', which replaces Le Chat, with a Work Mode (web and mobile) and a Code Mode (web) that runs remote coding sessions from GitHub projects through to pull requests. ([source](https://mistral.ai/news/vibe-agent/))
- In Vibe, 'every step is visible as it happens, and each tool call and reasoning chain is expandable to its inputs and outputs'. Work Mode shows a plan for approval before it runs, and its features include inline charts, a Canvas for drafting documents and scheduled runs. ([source](https://mistral.ai/news/vibe-agent/))
- Vibe is available on chat.mistral.ai, on mobile, as a VS Code side-panel extension and as a CLI. ([source](https://mistral.ai/news/vibe-agent/))
- Mistral models now power Firefox Smart Window (beta), Mozilla's AI browsing assistant. Mistral is fine-tuning them on regional languages and dialects and has agreed to zero data retention. ([source](https://mistral.ai/news/mistral-x-mozilla/))
- Recent announcements include a €3B Series D at a post-money valuation above €21 billion (Sep 8, 2026), Mistral Large 4 (Oct 6, 2026), a Munich hub focused on industrial AI (Sep 28, 2026) and remote agents in Vibe powered by Mistral Medium 3.5 (May 22, 2026). ([source](https://mistral.ai/news/))
- Wikipedia lists Mistral Medium 3.5 (April 2026, 128B parameters, modified MIT license) as the 'first flagship merged model'. It also reports that Mistral raised $830 million in March 2026 to build datacenters near Paris and in Sweden. ([source](https://en.wikipedia.org/wiki/Mistral_AI))
